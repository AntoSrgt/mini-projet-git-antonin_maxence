Command :
	git add : Get your modified files ready to save them
	git branch -D : Allows you to delete a branch 
	git checkout "name branch" : switch branches
	git checkout -b "name branch" : create and switch branches
	git commit -m "" : Permanently saves the prepared files along with a message describing what was done
	git init : Initialize Git
	git log : Shows the most recently completed commits
	git pull : Updates your local backup with data from Github 
	git push : Save the changes on Github
